# Elektronikprojekt – GitHub Pages

## Struktur

```text
/
├── index.html
├── dokumentation.html
├── impressum.html
├── datenschutz.html
├── style.css
└── images/
    ├── projekt-hero.jpg
    ├── aufbau-1.jpg
    ├── aufbau-2.jpg
    ├── platine.jpg
    ├── gehaeuse.jpg
    └── placeholder.svg
```

Die JPG-Dateien sind Platzhalter-Namen: Lege deine eigenen Bilder mit genau diesen Namen in `images/`.
Alternativ kannst du die Dateinamen direkt in den HTML-Dateien anpassen.

## Besucherzähler

In `index.html` und `dokumentation.html` ist jeweils ein Bereich markiert:

```html
<!-- HIER DEN EINBETTUNGSCODE VON BESUCHERZAEHLER-KOSTENLOS.DE EINFÜGEN -->
```

Dort den vom Anbieter bereitgestellten Einbettungscode einsetzen.

## GitHub Pages

1. Repository auf GitHub erstellen.
2. Alle Dateien in das Repository hochladen.
3. Unter **Settings → Pages** die Veröffentlichung aus dem gewünschten Branch aktivieren.
4. Anschließend ist `index.html` die Startseite.

## Vor Veröffentlichung

- Impressumsangaben ersetzen.
- Datenschutzerklärung an die tatsächlich eingesetzten Dienste und Datenflüsse anpassen.
- Eigene Projektbilder in `images/` ablegen.
- Besucherzähler-Code des Anbieters einsetzen.
- Projekttexte und technische Daten durch die realen Werte ersetzen.
